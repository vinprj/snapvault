# 🔖 SnapVault

Smart bookmark manager with collections, tags & beautiful link previews.

## Features
- 🔗 Save bookmarks with auto-fetched favicons
- 📁 Organize in collections
- 🏷️ Tag-based organization
- 🔍 Full-text search
- 🌙 Light/Dark mode
- 📱 Responsive grid layout
- 💾 Offline-first (LocalStorage)

## Tech Stack
- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Lucide Icons

## Getting Started
```bash
npm install
npm run dev
```
